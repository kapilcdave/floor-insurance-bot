# Security policy

Please report credential-handling or order-safety vulnerabilities privately via
GitHub's security-advisory feature rather than a public issue.

- Never paste Alpaca or Telegram secrets into an issue, log, screenshot, or
  committed file.
- Use paper-only API keys while evaluating the bot.
- Rotate any key that may have been exposed.
- The bot accepts credentials only from environment variables and never logs
  their values.
